# Hero Design Question

[x] Q: Should assassin 2 shot the backliner?

A:

If that assassin need a lot of setup, and assassin itself it the payoff of it. then yes.
But if that assassin don need setup (or minor setup), then no.

[x] Q: How big is a setup for 2 active mark and 1 item?

A:

If this setup consider decent work, then myconid 2-shot a enemy is justified.
Right now, I think Myconid is justified because:

- 2-shot 1 enemy isn't that big.
- 2 active mark and 1 item feel like a decent setup. Right now (24/10/69), there's no hero other than Myconid that can fit to the Elf team. That mean it quite a work to put Myconid in because he's the only one fit to the team.

In summary, it was justified for now.

[x] Q: A way to balance **On kill** trigger:

Normally, other tank heal through his skill mainly so it was easy to tweak. Assume that he use 100 mana to cast once, assume again that it take 10 sec to cast, and the skill heal for 1000, that mean this hero heal 10 hp/s.

From what you can see, when the value can turn into hp/s, it's easy to tweak/balance.

But troll is different to others tank. He healed for flat 150 when the enemy dies, we don't know when the enemy is going to die, so the value is harder to turn into hp/s which make it hard to tweak and balance.

A:

Making his skill work like a cashout, he build up his 1 time gauge every second, then the gauge pop when the enemy dies, turn the gauge into HP. Now his skill should be easier to tweak because it's basically work like he gain hp/s.

[x] Q: Should mana scale with auto-attack?

Right now (24/10/69), mana increase by 10 every auto-attack which is a big deal because there's hero that can give AS. So tank can attack very fast leading to him cast more skill and become tankier.

To put it simply, tank are tankier when he attack faster. Which is hard to balance because AS now give both more DPS and Tankiness.

A:

In Guildrun, the mana is increase per second not per auto-attack. I think that way the balancing is easier.
So with this info I am toward changing to mana/s instead.

But before changing, let try to see what we can do balance out AS make tank tankier.
Ummm..., I thought AS lead to being more tanky could create a unique identity and made the game more fun. But it wasn't neccessary since GuildRun don't use it and still be able to create a unique identity.

In summary, NO, mana shouldn't scale with auto-attack, let mana increase per second instead. That way the game is easier to balance.
