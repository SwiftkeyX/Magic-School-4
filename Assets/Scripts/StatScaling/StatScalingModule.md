# MagicSchool.StatScaling

One question: given a list of `StatRatio` and a hero's stats, what is this worth (`Scaling`). Also `Crit` (pseudo-random crit)
and `Omnivamp`. That question belongs to no one in particular - damage, heals and modifier
bonuses all ask it.

References **Contracts**. Referenced by **Modifiers, Skills, Combat, Items**.

The folder is `StatScaling/`, not `Scaling/`, because the namespace follows the folder and a namespace
`MagicSchool.Scaling` holding a class `Scaling` cannot be used unqualified.
