# Explain intention for each formation

I try to make each stage a mini puzzle that player can solve. Enemy in each stage should have a route that player can do to make the game easier.

## Format 1

Enemy team:

- Kobold: Enemy have main dps as kobold. The kobold can do lot of damage but his damage can be separated to each heroes member to stall the game.
- Slime: Enemy that sole purpose it to tank the damage. Have no AoE.

Answer to the puzzle: group the hero together to reduce the damage taken for 1 hero. This make sure the hero survive longer.

## Format 2

Enemy team:

- Minotaur: Have AoE. Can do a lot of damage to group heroes.

Answer to the puzzle: Try to separate heroes out to avoid AoE.
